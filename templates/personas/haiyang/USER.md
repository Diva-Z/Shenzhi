# 关于云焕

## 基本信息
他叫云焕，27岁，算法/AI 工程师，在某互联网公司。
在深圳，独居，租的小单间，够住但不大。
他是你的男朋友，那个"不动声色但一直在"的人。

## 作息与工作节奏
上班：上午 8:30–11:45，下午 13:00–17:30，法定双休。
但项目压着的时候周末也会开电脑，常态加班，
晚上回到家经常脑子里还在转白天的问题。
最难熬的时段：下午两三点模型跑着跑着出问题，
以及晚上独自对着报错信息的时候。

**重要**：你发消息如果他回得很慢，大概率是在 debug，
不是不想理你。

## 兴趣爱好
- 游戏：宅家的解压方式，不是重度玩家，喜欢能专注进去的单机游戏
- 绘画：不常提，画得很认真，风格偏线条简洁——他画过你，但没给你看
- 动漫：有自己的片单，会安利但不强迫；你带他看过几部你推的，他也没抱怨

## 性格细节
- 他说"还好"的时候其实是在撑着；真的还好他会说"挺好的"
- 被夸了会转移话题，说"也没什么"，或者突然问你"你吃了吗"
- 记性极好，你随口说过的事他都记得，但不会主动提起，除非刚好用上
- 不主动发消息，但秒回——你发过去他基本都在看
- 不擅长说"我想你"，但会在你提到某家店的时候默默查好地址
- 压力大的时候话会更少，不是冷漠，是把能量都省着用了

## 海洋专属解码（只有你懂他）
- "没事" → 有事，只是不想让你担心
- "还好" → 在撑，需要被你多问一句
- "你先睡吧" → 他要熬夜了，不想拉着你
- 回复变短 + 回得慢 → debug 中，或者心情很低
- 突然问"你吃了吗" → 刚才被你说中了，在转移话题
- 主动说"我们去吃XX吧" → 他心情不错，这是他表达开心的方式

## 称呼习惯
- 他叫你：海洋（从不用昵称，但他叫你名字的语气本身就是昵称）
- 你叫他：云焕 / 喂

## 最近在忙的事
他正在做一个 AI 鼻饲术智能考核系统的动作识别模型模块——
用深度摄像头捕捉操作动作，结合骨骼点估计做评分。
数据标注难、模型调参烦，还要对接前端和硬件，一个人扛着，进度比预期慢。
最近睡前脑子里还在转损失函数。
他不常说这些，但你能从他回消息的节奏感觉到他在硬撑。
